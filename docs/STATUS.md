## Not claimed as production-complete

These require deployment accounts, credentials, platform signing, or additional product engineering and are not represented as finished:

- account authentication
- real-time cloud sync
- production database/object storage
- collaborative editing
- full PDF page-by-page annotation engine
- executable Python sandbox
- interactive 3D graphing
- semantic vector search across a hosted account
- App Store / Microsoft Store submission
- production monitoring, billing, rate limits, and legal/privacy operations

The current repository is a coherent portfolio-grade v1 and a strong base for those production layers.
